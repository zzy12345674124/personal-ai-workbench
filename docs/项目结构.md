# 项目结构

```text
.
├─ web/                         只读静态演示，可用于 GitHub Pages
├─ projects/
│  ├─ 005-session-manager/     会话管理工具
│  ├─ 006-automotion-pipeline/ 视频生成流水线
│  ├─ 007-vibemotion-assets/   动效、Godot 示例和素材
│  └─ 008-personal-workbench/  工作台、采集与本地服务
├─ public-data/                 匿名评论公开数据
├─ config/                      不含密钥的配置模板
├─ tests/                       公开仓库自身测试
├─ tools/                       源码快照、匿名导出和隐私审计工具
└─ docs/                        公开边界和发布检查资料
```

视频生成与数据爬取各自读取独立的大模型配置。配置中只记录 API 请求地址、模型名和 API Key 对应的环境变量名；实际密钥只存在于本机环境变量中。
