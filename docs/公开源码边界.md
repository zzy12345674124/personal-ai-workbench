# 公开源码边界

## 纳入仓库

- 005、006、007、008 的业务源码、测试、依赖清单和构建配置。
- 运行所需的示例配置，但不包含真实密钥。

## 不纳入仓库

- `.env`、Cookie、Token、API Key、浏览器登录资料。
- 昵称、用户 ID、主页地址及其他可关联个人身份的字段。
- 依赖目录、虚拟环境、缓存和临时目录。
- 数据库、运行日志、录音、生成视频及可重新生成的构建产物。
- 个人绝对路径、内部协作说明和项目过程日志。

## 大模型配置边界

视频生成和数据爬取是两个独立调用场景。任一场景需要大模型时，用户均可分别填写请求地址、模型名称，并通过本地环境变量提供 API Key。两者可以使用不同服务商；未启用时不得发起网络请求。

配置文件只保存 API Key 对应的环境变量名称，不保存密钥本身。错误信息不得包含请求头、完整请求体或密钥值。
