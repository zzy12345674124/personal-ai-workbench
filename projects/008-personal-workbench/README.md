# 个人工作台

3X-UI 式个人工作台：左侧功能导航 + 右侧大屏工具区。

## 启动

```bash
node server/server.js
# 浏览器打开 http://127.0.0.1:8080
```

## 工具

- 视频生成：支持输入主题或本地口述转写，再桥接 project_006 流水线（文案分镜 → 人工确认 → 渲染）
- 模板实时预览：在工作台内嵌 006 Remotion Studio，支持检测/手动启动本地预览服务与 Props 调参
- 素材预览器：读取 project_007 工作台素材
- 会话管家：project_005 状态只读面板
- 多平台评论采集：抖音、小红书、B站共用本地任务框架与 CloakBrowser；按平台隔离结果，支持暂停、停止、限流冷却和人工验证状态，不调用大模型即可采集
- 评论数据：三平台结果统一增量写入本地 SQLite，可按平台、发布日期、评论类型、关键词和排序方式筛选
- 更新日志：查看 v1.0.0 至当前版本的功能与修复记录

口述转写使用本地 `faster-whisper-base`：浏览器录音经 FFmpeg 转为 PCM WAV 后在 CPU 上离线识别，原始音频识别结束即删除。运行包隔离于 `runtime/voice-python/`，模型复用本机 Hugging Face 缓存。

## 测试

```bash
npm run verify
```

该命令会同时运行工作台前后端测试与抖音、小红书、B站采集解析器的虚拟数据测试，不触碰真实账号或真实评论。
