# 个人 Harness 与 AutoMotion

本项目建设一个可复用的个人 AI Harness，并用 AutoMotion 验证它：输入一个 AI、软件或技术主题，系统完成研究、文案、分镜、免费配音、同步字幕、程序化动画、视觉复核与 MP4 渲染。

## 当前状态

设计与实施计划已批准，当前执行第 0 轮可行性验证。本地预检脚本与报告已建立；尚未安装依赖或修改模型配置，模型联网验证仍需单独授权。

## 核心工作方式

- 正常模式：Codex 主导，Claude CLI + DeepSeek V4 Flash 挑战与复核。
- 降级模式：Codex额度不足时保存断点，由 Flash 接管文本、代码与编排，MiMo-V2.5 检查关键帧（通义 qwen3.5-omni-flash 为备选）。
- 人工闸门：文案与分镜完成后暂停，用户批准后才生成配音和动画。
- 技术路线：Node.js/TypeScript 编排器 + Remotion/React 动画 + 本地 Schema 校验。

## 预期正式产物

每条通过验收的视频包包含 MP4、文案、结构化分镜、来源、评估报告、运行清单和可重新渲染的场景数据。临时运行数据放在工作区统一的 `AI工作区`，不与正式产物混放。
