# Personal AI Workbench

一个面向个人内容生产、数据采集与任务管理的模块化工作台。

本仓库用于整理会话管家、视频流水线、素材系统和个人工作台的完整可构建源码，并直接提供与本人日常使用版本一致的工作台前端界面。公开页面不另做项目介绍式演示，只关闭会触发真实账号、浏览器登录、文件写入或付费 API 的操作。

## 项目亮点

- 使用原生 JavaScript、ES Modules 与 Node.js 构建模块化 Web 工作台。
- 通过工具注册表和动态加载机制管理 8 个功能面板。
- 打通“录音转写 - 内容生成 - 人工确认 - 视频渲染 - 视觉质检”工作流。
- 设计多平台任务框架，将任务调度、平台适配和数据存储解耦。
- 使用状态机处理登录失效、限流、暂停、人工验证和页面变化等异常状态。
- 使用 SQLite 统一存储评论数据，并提供筛选与可视化分析。
- 完整本地项目通过 154 项 JavaScript 测试和 36 项 Python 测试。
- 完成对 5 个 B 站视频、183 条评论的真实采集验证。

## 功能模块

1. 多平台任务管理
2. 评论数据分析
3. 视频生成
4. 本地语音转写
5. 模板实时预览
6. 素材预览与参数编辑
7. 会话状态面板
8. 版本更新日志

## 技术栈

- 前端：JavaScript、HTML、CSS、ES Modules
- 服务端：Node.js
- 数据处理：Python、SQLite
- 多媒体：FFmpeg、Remotion、faster-whisper
- 浏览器自动化：Selenium、CloakBrowser
- 测试：Vitest、Python unittest

## 公开演示版

公开页面采用真实工作台界面和只读浏览模式，提供：

- 与本地版本一致的八工具工作台界面与导航
- 视频任务状态演示
- 评论筛选与数据看板
- 多平台采集状态机演示
- 90 秒招聘者导览模式

公开页面不会执行真实采集、平台登录、录音上传、视频渲染、文件删除或付费 API 调用；评论数据面板只读取已审核的匿名样本。

## 项目架构

仓库按四个可独立理解的子项目组织：

| 目录 | 内容 |
| --- | --- |
| `projects/005-session-manager` | 会话管理桌面工具 |
| `projects/006-automotion-pipeline` | 内容生成、视频渲染与质检流水线 |
| `projects/007-vibemotion-assets` | 动效、Godot 示例与素材系统 |
| `projects/008-personal-workbench` | 工作台前端、Node.js 服务和采集工具 |

整体架构由以下部分组成：

- 原生 JavaScript 前端负责界面、交互和任务状态展示。
- Node.js 服务端负责静态资源、接口校验和本地工具桥接。
- Python 脚本负责平台数据解析、语音转写及数据处理。
- SQLite 负责评论数据的统一存储与查询。
- FFmpeg 与 Remotion 负责音视频处理和视频渲染。

公开仓库保留四个项目经过脱敏、可重新安装构建的源码，不包含私人运行环境和可重新生成的产物。

## 安全与隐私

本仓库不会包含：

- API 密钥及本地环境配置
- Cookie 和浏览器登录资料
- 昵称、用户 ID、主页地址及其他可关联个人身份的字段
- SQLite 数据库、运行日志和生成视频
- 本机绝对路径
- 私人项目日志及内部协作记录

## 本地预览

在 `web/` 目录启动任意静态 HTTP 服务，例如：

```bash
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。不要直接双击 `index.html`，浏览器会限制 ES Modules 和 JSON 文件读取。
